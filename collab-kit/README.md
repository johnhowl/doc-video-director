# {{PROJECT}} · 总导演 ↔ 执行代理 协作说明

本目录 `.ai-collab/` 是总导演代理（如 Claude Code）与执行代理（如 Codex）的共享协作区，由 doc-video-director skill 的 `init-collab.mjs` 生成。**主方式是文件交互**：用户同时开着两个代理终端，两边通过这里的结构化文件沟通，用户只需在中间传一句话。命令行互调是可选项。

## 分工

- **总导演（Director）**：文案、逐镜设计稿、难动画代码与演示片、派工单、审查回执、裁决提问、制定未规定的规则。只写方案区 `{{PLAN_DIR}}/` 与本目录中自己的文件。
- **执行（Executor）**：按工单执行：安装插件和项目依赖、调用本地或云端视频接口、HyperFrames / Remotion / ffmpeg、配音、剪辑、验收；指导用户下载模型、开通 key；写回执、提问、收口报告。不写方案区。
- **用户**：在关口拍板（清理计划、风格板、动画评审、样音、样片、预算、下载与开通账号、发布），也可以直接审查和归口。

## 文件约定（每张工单一个目录 `work-orders/WO-日期-序号/`）

| 文件 | 谁写 | 内容（格式见 `schemas/`） |
|---|---|---|
| order.json / order.md | 总导演 | 工单：目标、必读、步骤、镜头、交付、验收、关口、预算、禁止 |
| STATUS.json | 执行 | 执行中 / 受阻 / 等用户（`collab.mjs state`） |
| report-rN.json | 执行 | 回执：产出、逐镜结果、自检、花费、偏离、待问 |
| query-rN.json | 执行 | 提问或异议（带证据） |
| resolution-rN.json | 总导演 | 裁决，取代工单原文 |
| review-rN.json | 总导演 | 审查：pass / pass_with_notes / revise / fail，逐镜问题与必改项 |
| user-decision-rN.json | 用户说话所在终端的一方如实记录 | 用户对指定回执或提问的结论（原话照录），绑定原文件 SHA256 |
| closeout-rN.json | 执行 | 收口报告：写明归口方（用户 / 总导演）、批准依据文件及哈希、对应回执及哈希 |
| experiment-rN.json | 执行 | 引擎或参数对比试验 |

总账：`ledger.json`（数据）→ `LEDGER.md`（全部集数的进度、现在轮到谁、每一步完成后交给谁）；工单看板：`BOARD.md`。都由 `node .ai-collab/bin/collab.mjs status` 生成，不要手改。

## 审查与归口（收口）

- **审查**：用户和总导演都可以审查回执。总导演写 `review-rN.json`；用户的审查以 `user-decision-rN.json` 记录原话。
- **归口**：用户或总导演**任一方**明确批准**最新**回执，且没有未裁决的提问，即可收口；执行代理不能自己批准自己。
- **收口报告**：执行代理运行 `collab.mjs closeout <工单号>` 写 `closeout-rN.json`，并在终端向用户汇报时说明“本工单由用户归口”或“由总导演归口”。
- 回执被批准后若再改动，原批准作废（哈希对不上）。
- 意见不一致时以用户结论为准；总导演的不同意见写进后续工单或裁决，不推翻用户已归口的收口。

## 权限分级

- **常规状态**：执行代理可直接更新自己的执行状态、回执、提问和自己负责的总账步骤，不必逐次请示。
- **A 级（执行代理直接做，记入 FIXLOG.md）**：不改内容和设计的技术修复：渲染失败、编码参数、路径、按原设计重渲染、镜头时长 ±10% 对齐配音。
- **B 级（先写 query 等总导演裁决）**：改文案、画面设计、镜头类别或引擎分工、验收标准、事实或科学内容、方案区任何文件、协作规则。
- **C 级（必须用户决定）**：超预算花费、下载大模型、开通或充值账号、覆盖或删除受保护成片、替换发布目录、发布。
- **返工可以据理力争**：执行代理认为返工要求有误、不适用或遗漏上层问题时，写 query 并附原要求、位置、可重复证据和建议；无争议部分继续推进，争议部分在裁决前保留产物，涉及花费或覆盖时停在提交前。

## 传话口令（用户在两个终端之间说）

- 对执行代理：“处理新工单” / “继续 WO-xxx” / “我已经下载完了” / “WO-xxx 通过”
- 对总导演：“看回执” / “看提问” / “派下一批工单” / “WO-xxx 通过”

## 工具

`node .ai-collab/bin/collab.mjs`：`status`、`ledger`、`stage`（更新总账）、`new`、`validate`、`render`、`state`、`sheet`（评审拼图）、`closeout`、`watch`；可选互调：`dispatch`（总导演调用 `codex exec` 执行工单）、`ask-claude`（执行代理调用 `claude -p` 裁决提问）。自测：`node .ai-collab/bin/collab.test.mjs`。
