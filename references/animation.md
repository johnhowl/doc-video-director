# 代码动画：演示片、经验与风格库

需要精确结构的画面（分子机制、细胞器、器官、肌肉透视、网络图）一律用代码做。代码动画是帧的纯函数，任意帧可单独渲染，适合并行，也便于反复修改。

## 流程：设计稿 → 代码 → 演示片 → 用户评审

1. 设计稿里每个动画镜头写：要讲清的一句话、结构清单、动作步骤（每步 2–4 秒）、机位、标签出现时间、科学核对点，以及一段**视频备用提示词**。
2. 总导演把难的镜头直接写成代码（简单的交给执行代理），合成 ID 与镜号一致。
3. 渲染**带审片标注**的演示片（镜号、标题、关键说明），交用户看；设计稿文末评审表逐镜填“通过 / 改动画 / 改用视频生成”。
4. 通过的用 `--final` 渲染无标注版入片；改用视频生成的直接用备用提示词，不再改代码。正式成片里的文字由幻灯片层按本集风格排版。

## 起步工程 `templates/remotion-3d/`

- `src/lib/Stage.tsx`：画布、环境光（RoomEnvironment）、主光与轮廓光、漂浮微粒、相机、审片标注层
- `src/lib/materials.tsx`：半透明生物膜、柔和蜡质材质
- `src/lib/core.ts`：缓动、分段进度、确定性随机数、配色
- `src/scenes/examples.tsx`：细胞工厂飞入、DNA 断裂修复（右手双螺旋）、端粒随分裂缩短三个示例
- `render.mjs`：`--stills`（每合成 3 张静帧，几秒出结果）、`--only=`、`--final`；`DEMO_JOBS` 控制并发

## 拍法：参照医学科教片

- **连续推进**：器官 → 组织 → 细胞一路推进，不硬切；跨尺度时用一道柔光或景深转场。器官用开放解剖模型，只出现器官本身，不经过体表。
- **第一人称（POV）**：适当让镜头跟着运动走——骑着一个红细胞穿过血管、跟着一个分子进入细胞。血管内壁用内皮细胞纹理，镜头带“头灯”式补光，近裁剪面调小（约 0.005）；大动脉里随心跳一冲一冲，毛细血管里平稳。一集里同一种拍法只用一次，其他镜头换成跟拍横移、切面、分屏对比。
- **切面与分层**：结构用切面（如肌束横截面、血管壁三层）和半透明分层讲，比侧面看更像教科书图、更好懂。
- **代码做不好就换路**：演示片审下来不满意，直接改用云端视频生成（设计稿里的视频备用提示词），不在代码上反复磨。
- **音效对齐**：心跳等节拍写成固定周期（如每 0.9 秒一次），设计稿写明第一心音落在哪些秒数，剪辑时按帧配音效。

## 踩过的坑（写进代码前先看）

| 问题 | 原因 | 做法 |
|---|---|---|
| 画面发白、颜色淡 | 环境光太强 + 色调映射 | 环境光强度约 0.4、曝光约 0.9，颜色选饱和一些 |
| 模型名字匹配不上，部分肌肉不亮 | GLTFLoader 把节点名中的空格换成下划线 | 匹配前把 `_` 换回空格 |
| 某些网格看不见 | 法线朝内被背面剔除 | 替换材质时设 `side: DoubleSide` |
| 偶发空白帧 | 模型还没画进画布就截帧；或浏览器 WebGL 上下文不够 | `delayRender` 在模型进入场景后再等两帧才 `continueRender`；大模型降低并发 |
| 机位贴脸、遮挡主体 | 随机摆放的物体落在相机路径上 | 生成布局时把相机前方锥体内的物体移开 |
| 平板方块像“锯齿” | 用盒子表示有机结构 | 用压扁的球体、胶囊、管道几何 |
| 标签小、像注释 | 说明写在画面里 | 画面只留名词短语，≥40px，停留 ≥3 秒；说明交给旁白 |
| 进入血管时整屏一片红 | 镜头从器官内部穿过、单面材质从里面看不见 | 从血管外侧对准管壁、穿壁进入，再转向顺流方向 |
| 侧面看肌纤维，前后对比看不出差别 | 圆柱表面纹理太抢眼，小结构被挡住 | 改用横截面：毛细血管是纤维间的红点、线粒体是截面上的橙点 |
| Windows 上 Node 22 渲染脚本直接崩溃、没有任何输出 | `fs.cpSync` 遇到含中文的路径 | 改成逐个文件 `copyFileSync` |

## 风格参考：lemo-opuscar

[lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) 是一套“用代码做片”的风格库：几十种影片风格，每种是一段风格提示词加一支完全用代码做的示范片（canvas / WebGL 逐帧渲染，不用视频模型），专为 Claude Opus 调过。对科教纪录片最有用的是其中的 **Edit & Documentary（剪辑与纪录片）** 和 **Evidence Films（证据片，每个数字有出处）** 两组，以及图表、地图、黑板、手账类风格。

**怎么用**

- 安装（Claude Code）：`claude plugin marketplace add lemomo-ai/lemo-opuscar`，再 `claude plugin install lemo-opuscar@lemolab`；首次使用会把风格提示词与工具下载到 `~/lemo-opuscar`。其他代理可把仓库里的 `plugin/skills/lemo-opuscar/` 复制进自己的 skills 目录。
- 用在**幻灯片**和**非结构性动画**：按场景挑风格（生活段落、证据数据段、地图、清单），让同一集里不同段落的幻灯片有不同基调，避免全片一个模板。
- 需要精确科学结构的镜头仍用本 skill 的三维起步工程；风格库只决定版式、配色、质感和运动语言。
- 每集选用的风格写进设计稿“本集幻灯片风格”，用户审风格板时一起确认。
