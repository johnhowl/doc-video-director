# 模板

## 文案自查表

- [ ] 第一行：一句话核心信息
- [ ] 前五秒的钩子画面写明了
- [ ] 每个知识点有一个比喻和一个画面
- [ ] 专业名词第一次出现时紧跟一句白话解释
- [ ] 数字都有来源（写进 SOURCES）
- [ ] 风险提示集中在“证据边界”一段
- [ ] 结尾有“三件事”和下一集预告
- [ ] 健康/医疗/理财等类别：结尾有一句免责口播
- [ ] 数字写成汉字，方便配音读准
- [ ] 总字数约 2400–2600（约 9 分半到 10 分钟）

## 分镜表

|---|---|---|---|---|---|---|---|---|---|---|---|
| 04-02 | 现实视频 | 92.0–98.5 | 7 | 特写 | 平视略俯 | 缓推 | 鞋带头在 62% | 塑料套边缘慢慢开裂 | 端粒=保护帽 | 叠化到三维染色体末端 | GPT 首尾帧 → Seedance Mini 720p |

镜号用“段落号-镜头号”。每集分镜表另附：场景色表（每场 3–5 个颜色 + 灰度测试图）、人物表（引用系列人物登记）。

## 图像提示词（七段式，用于 GPT 或 Seedream）

```
【画风】写实纪录片摄影，35mm 胶片质感，自然光，暖中性色调，皮肤真实质感，不磨皮。（引用系列风格板）
【镜头】中景，略低机位，50mm 视角。
【构图与配色】人物在画面右侧约 62% 处，左侧留出楼梯延伸的空间；墙面浅灰绿，扶手深棕，窗光暖白。
【人物】（仅 Seedream 人像帧）约 55 岁中国女性，齐肩短发略花白，中等身材，藏青色针织开衫，米色长裤，白色运动鞋，手腕一只旧手表。
【瞬间】她停在楼梯拐角，一手扶栏杆，微微弯腰喘气，视线看向上方。
【光线与质感】上午，楼道窗户从左上方进光，空气里有细微浮尘。
【约束】画面中只有这一个人；无文字、无标识、无水印；手指数量正确；不出现镜子和倒影。
```

首帧和尾帧各写一份，并写明两帧的差别（“尾帧：她已抬起头，深吸一口气，身体直起来”）。

## 视频提示词（七段式，用于 Seedance）

```
【画风】与首帧一致的写实纪录片质感，自然光，暖中性色调。
【镜头】时长 7 秒，中景，机位固定，镜头从第 2 秒开始非常缓慢地向前推进约 5%，一镜到底，没有剪切。
【构图与配色】与首帧一致：人物在画面右侧，左侧是向上的楼梯；墙面浅灰绿。
【人物】约 55 岁中国女性，藏青色针织开衫，米色长裤（与首帧完全一致，全程不变）。
【逐秒】
0–0.2 秒：画面完全静止，与首帧一致。
0.2–3 秒：她扶着栏杆，胸口起伏，呼吸明显，头微低。
3–5 秒：她慢慢抬起头，看向画面左上方的楼梯。
5–6.7 秒：她深吸一口气，身体直起来，右手仍扶着栏杆。
最后 0.3 秒：定格，与尾帧一致。
【声音】只有她的呼吸声和远处楼道的回声，没有说话，没有音乐。
【约束】画面中只有她一个人；面部和身材全程不变；一镜到底；没有文字、字幕和水印；手只放在栏杆上，不拿任何物品。
```

写法要点（原文经验）：
- 用正面描述，少写“不要……”（模型对否定句常常无效）。
- 方向按画面左右写，不写“她的左边”。
- 数量写明确。
- 群体动作写明先后顺序，不写“同时”。
- 需要外力的物体（风吹窗帘）不要让手去碰。
- 容易被误用的道具（水壶会一直倒水）不要放进动作镜头。
- 第一个 0.2 秒和最后 0.3 秒写成静止，便于剪辑。

## 动画镜头说明（三维机制）

```
镜号 / 时长 / 要讲清的一句话
结构清单：（如 DNA 右手双螺旋、碱基对可见；修复蛋白夹住断口）
动作步骤：1. … 2. … 3. …（每步 2–4 秒，与旁白关键词对齐）
摄影：起始机位、焦点跟随对象、推进不超过 10%
材质与光：引用系列“细胞工厂”资产库
标签：哪一秒出现什么字（≥40px，停留≥3 秒）
科学核对：参考来源 / 需要审核确认的点
```

## 项目设定

在项目根目录建 `PROJECT.md`，至少包含：

```
# 项目设定
- 作品名 / 集数 / 单集时长：
- 一句话定位：
- 目标观众画像：（年龄、文化程度、观看设备与平台）
- 配音：（TTS 平台、声音 ID、模型、参数；分集规则）
- 视觉风格：（风格板路径；写实/插画；调色）
- 人物规则：（年龄范围；能否跨集复用；着装与禁止项）
- 科学/事实标准：（来源优先级；证据分级；禁止的说法）
- 署名规则：（片尾固定行；AI 生成声明；第三方素材写法）
- 禁止内容：
- 预算：（每集视频生成上限；谁可以批准）
- 已有素材与管线：（三维资产库、模板、字体、音乐许可）
- 不得改动的文件或成片：
```

## 免责声明

- 片头声明卡（约 4 秒）：健康科普，不构成医疗建议。本节目内容仅供健康知识普及，不能代替医生的诊断和治疗。调整运动、饮食、用药或补充剂之前，请先咨询医生或其他专业人员。
- 结尾口播：温馨提醒：这个节目只做健康科普，不能代替医生。改变运动、饮食和用药之前，请先问问医生。
- 片尾完整声明（约 6 秒）：本节目为健康科普内容，根据公开发表的科学研究和权威指南整理，仅供参考，不构成任何医疗建议、诊断或治疗方案。每个人的健康状况不同，如有疾病、长期用药、近期受伤或任何不适，请在医生或专业人员指导下进行调整。观众据此作出的个人健康决定，请结合自身情况并遵从专业意见。本节目不推荐、不销售任何药品、保健品或商品。
- 发布文案：【免责声明】本视频为健康科普，内容整理自公开科学研究和权威指南，仅供参考，不构成医疗建议。如有健康问题，请咨询医生。
